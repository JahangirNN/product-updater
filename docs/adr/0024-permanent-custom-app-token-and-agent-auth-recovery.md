# ADR 0024: Permanent Custom App Admin API Token Architecture & Autonomous Agent Auth Recovery Protocol

## Status
Accepted

## Date
2026-10-06

## Context
During continuous background freshner daemon execution (`scripts/run_freshner_daemon.py`), GraphQL calls to Shopify Admin repeatedly returned:
`GraphQL Error: HTTP 401 Unauthorized: Shopify session token expired for hewmvw-am.myshopify.com`

Investigating the root cause revealed:
1. **Ephemeral CLI OAuth Lifespan**: Tokens generated by `shopify login` stored in `%APPDATA%\shopify-cli-kit-nodejs\Config\config.json` expire within ~24 hours and contain no refresh token.
2. **Subprocess Pipe Deadlock on Windows**: Attempting headless silent CLI refresh (`shopify.cmd theme list`) when expired spawns interactive OAuth child processes waiting for browser approval, which hang or time out in background daemons.
3. **Flawed Token Resolution Hierarchy**: `storage/shopify_auth.py` previously read the CLI config file without parsing `expiresAt`. If expired, it continued passing dead tokens to HTTP requests and failed to fall back to static configuration.
4. **Daemon Error Flood**: Every delta sync attempt continuously triggered failing GraphQL requests, flooding log files with 401 exceptions.

---

## Decisions

### 1. Hierarchical Credential Resolution with Auto-Refreshing Client Credentials
`storage/shopify_auth.py::get_shopify_credentials` resolves tokens in strict hierarchical order:
1. **Priority 1 (Headless Auto-Refreshing)**: Custom App Client Credentials Grant (`SHOPIFY_CLIENT_ID` + `SHOPIFY_CLIENT_SECRET` via `POST https://{shop}/admin/oauth/access_token`). Automatically mints 24-hour Admin API access tokens on demand and auto-refreshes seamlessly (300s buffer before expiry). If a 401 occurs at any time, it auto-refreshes and retries the request without failing. Zero manual logins required.
2. **Priority 2 (Permanent Static Token)**: `config/shopify_config.json` -> `access_token` (Custom App static `shpat_` token).
3. **Priority 3 (Permanent Environment Token)**: `SHOPIFY_ADMIN_ACCESS_TOKEN` environment variable.
4. **Priority 4 (Ephemeral CLI Session)**: `%APPDATA%\shopify-cli-kit-nodejs\Config\config.json` -> Validated against `expiresAt`. If `now_utc >= expires_at`, the token is flagged expired and ignored.

### 2. Shopify Custom App Credentials & App Automation Token (`atkn_`)
- **Client ID & Client Secret**: Used by the backend Python service for the headless OAuth Client Credentials Grant.
- **App Automation Token (`atkn_`)**: Scoped to the app in the Shopify Developer Dashboard. Used as `SHOPIFY_APP_AUTOMATION_TOKEN` and `SHOPIFY_CLI_PARTNERS_TOKEN` for non-interactive CI/CD and CLI deployments. Valid for 6 months.
- **Required Scopes**: `write_products`, `read_products`, `write_themes`, `read_themes`, `write_inventory`, `read_inventory`, `write_files`, `read_files`. Approved via 1-click merchant authorization URL:
  `https://admin.shopify.com/store/hewmvw-am/oauth/authorize?client_id=5dadd21e620a72d0f0617d58bbd8c5b9&scope=write_products,read_products,write_themes,read_themes,write_inventory,read_inventory,write_files,read_files`
- **Clean Header Format**: `execute_shopify_graphql` supplies `X-Shopify-Access-Token` without cookies or basic authentication conflicts.

### 3. Authentication Circuit Breaker
- When an HTTP 401 is encountered, `trip_auth_circuit_breaker()` activates a 300-second (5-minute) cooldown.
- Subsequent calls within the cooldown window return immediately without making wasteful network calls or spamming log files.
- Successful 200 responses automatically reset the circuit breaker.

### 4. Non-Blocking CLI Refresh
- `refresh_cli_session` no longer executes a blocking `subprocess.run(["shopify.cmd", ...])`. It logs immediate, clear guidance and returns `False` non-blockingly.

### 5. Dedicated Operational Tools
- `scripts/check_shopify_auth.py`: Inspects active token status, expiry timestamps, and verifies live GraphQL connectivity.
- `scripts/setup_permanent_shopify_token.py`: Validates custom app tokens against live Shopify Admin and saves to `config/shopify_config.json`.
- `scripts/relogin_shopify_cli.py`: Interactive CLI wrapper for browser OAuth when temporary testing is needed.

### 6. Autonomous Agent Protocol & Skill Integration
Updated `shopify-admin` skill and created `shopify-authentication-protocol.md` rule:
- Agents encountering 401 run diagnostics via `scripts/check_shopify_auth.py`.
- Guide the user to configure the permanent Custom App token.
- Once configured, automatically drain pending delta events via `drain_delta_events_queue()`.

---

## Consequences
- **Zero Daemon Interruption**: Custom App tokens run 24/7/365 without token expiration.
- **Clean Headless Execution**: Zero blocking subprocesses or pipe deadlocks on Windows.
- **Self-Healing Delta Engine**: Price and inventory shifts that queued during an outage automatically drain upon reconnection.
